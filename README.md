# InkDB

A simple and fast B-tree database written in Rust.

## Overview

InkDB is an experimental storage engine built around a clean, page-oriented B-tree design.
The name *Ink* comes from thinking about B-trees as the tentacles of a leviathan-like creature rather than rigid trees.

## Status

Work in progress. APIs and internals are subject to change.
